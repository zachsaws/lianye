# 联野新版独立预览

以 XMind 的表达精度与整页一致性为参照，采用原创纸面插画、可展开的渠道全景与三种具体合作产物。渠道段已按最新反馈撤回照片瀑布流：不要求每个软件渠道或经营入口都拥有场所照片。

本目录是本轮唯一候选。渠道球面已按用户反馈退回，当前采用六个硬件经营场景和四个软件方向展开原有资料。当前渠道段说明与核验见 docs/channel-world.md。历史研究稿与退回截图保留在旧目录和 qa/ 中，旧图不属于当前发布文件。公开预览位于 https://zachsaws.github.io/lianye/next/ ，历史主站与 scene/ 保留。

## 文件

- index.html、style.css：三段内容与响应式构图。
- channel-world.js：场景全景、站内展开、键盘与滚动联动。
- app.js：合作状态、说明弹窗与真实邮箱复制。
- assets/network-data.js：带公开来源的渠道入口分类。它不是签约名单。
- assets/mark.svg：品牌标记。
- docs/design.md、docs/narrative.md、docs/qa.md：设计、叙事与审查记录。
- qa/：当前截图、录屏与浏览器检查。

纯静态页面，无外部字体、图库依赖或后端提交。可用任意静态服务运行。现有本地入口为 http://127.0.0.1:8829/design-review/ 。

## 核验范围

已完成Chrome1440×1000、390×844、320×740的功能、布局、触控、键盘、复制替代路径与对话框检查。来源与合作构想的边界见页面“关于本页”和 docs/。没有真机、微信、独立访客理解或商业结果验证。内部自审不代表用户审美认可。

当前渠道段复测脚本：qa/verify-channel-world.cjs。旧verify-site.cjs对应此前球面版本，保留作历史记录。当前视觉候选按新的全景构图评审，不沿用此前球面方案的品质判断。
