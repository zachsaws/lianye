# 联野新版预览 · 设计规范

本稿以 XMind 的任务表达、排版层级与整页一致性为参照，采用原创纸面插画与可展开的渠道全景。渠道段按用户最新反馈，撤回依赖场所照片的瀑布流，不让图片是否存在决定哪些渠道可以呈现。

## 构图与材料

首屏保留“好产品，不该输在渠道上”，用新品、体验与内容三个小场景围绕主张。桌面保留外围材料，手机改为上下错落的两件材料，避免把桌面四角构图直接缩小。

渠道段使用同一张铺开的纸面，按经营场景呈现具名经营者。硬件优先，软件另有对应内容。原资料中的同一主体别名与关联社群归并展示，避免为了显大而重复独立列出。场景标题在站内展开完整细分类与名称，没有渠道外跳或数量成绩宣传。

第三段以同一款原创 AI 记录工具呈现三件合作产物：创作者的实测内容、社群的任务试用活动、服务商的客户引入提案。每种状态均说明伙伴的参与理由与品牌可以承接的事情。界面、图形和例句用于说明合作构想。

## 基础样式

- 字体：系统中文无衬线，以 PingFang SC 为优先；标题字重约600–680，正文400。
- 纸面：#FAF9F5；正文：#242622；次级可读文字：#66705A。
- 场景底色：鼠尾草绿 #E9EDDF，少量淡紫 #E9E3F2 用于软件材料。
- 橙色用于焦点与联系动作。白字按钮使用 #BB4627，避免亮橙按钮的文字对比度不足。
- 桌面主要内容宽度1280px；手机保留24px左右边距。无固定导航遮挡内容。
- 图像为原创 SVG、HTML 与 CSS 构图，无远程图片、图库拼贴或依赖陌生渠道素材的占位海报。

## 运动与操作

首屏材料保留短入场。渠道全景随正常页面滚动显露后续真实名称，点击场景标题展开完整内容；关闭后恢复页面位置与键盘焦点。第三段保留不同合作产物之间的短过渡。

系统“减少动态”偏好关闭入场与过渡。渠道全景保留正常纵向页面滚动，场景标题提供触控与键盘操作。展开面板内可阅读全部名称，支持Esc、返回按钮、焦点约束与关闭回退。邮箱可点击发信，也可以直接复制；复制受限时选择真实邮箱文本供手动复制。
