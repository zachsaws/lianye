# 联野新版预览 · 设计规范

本稿以 XMind 的任务表达、排版层级与整页一致性为参照，采用原创纸面插画与可交互矢量网络。渠道段按用户最新反馈，撤回依赖场所照片的瀑布流，不让图片是否存在决定哪些渠道可以呈现。

## 构图与材料

首屏保留“好产品，不该输在渠道上”，用新品、体验与内容三个小场景围绕主张。桌面保留外围材料，手机改为上下错落的两件材料，避免把桌面四角构图直接缩小。

渠道段以一个可拖动的球面组织入口，右侧保留可读、可点击的分类与名称。软件和硬件各有六个探索方向，每个方向展示四个具体入口。数量用于内部描述，不在页面当作已建立网络的规模宣传。连线表达当前探索方向，不表示经营者相互合作或联野已签约。

第三段以同一款原创 AI 记录工具呈现三件合作产物：创作者的实测内容、社群的任务试用活动、服务商的客户引入提案。每种状态均说明伙伴的参与理由与品牌可以承接的事情。界面、图形和例句用于说明合作构想。

## 基础样式

- 字体：系统中文无衬线，以 PingFang SC 为优先；标题字重约600–680，正文400。
- 纸面：#FAF9F5；正文：#242622；次级可读文字：#66705A。
- 场景底色：鼠尾草绿 #E9EDDF，少量淡紫 #E9E3F2 用于软件材料。
- 橙色用于焦点与联系动作。白字按钮使用 #BB4627，避免亮橙按钮的文字对比度不足。
- 桌面主要内容宽度1280px；手机保留24px左右边距。无固定导航遮挡内容。
- 图像为原创 SVG、HTML 与 CSS 构图，无远程图片、图库拼贴或依赖陌生渠道素材的占位海报。

## 运动与操作

首屏材料有一次短入场；渠道球面在进入视口后短暂转入，1.6秒后停止，之后由用户拖动或键盘方向键驱动。切换渠道方向带来球面视角与右侧入口同步变化。第三段改变实际合作画面，并有短过渡。

系统“减少动态”偏好关闭入场与过渡。球面支持水平触控拖动，保留纵向页面滚动。右侧名称与分类提供完整的触控、键盘替代路径。邮箱可点击发信，也可以直接复制；复制受限时选择真实邮箱文本供手动复制。
