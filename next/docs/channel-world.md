# 渠道段重构

视觉主张：一组统一纸面、线描与字体秩序的渠道全景，具名经营者构成主体，场景图形帮助读者识别不同生活与经营方向。

内容计划：保持首屏与商业化段稳定。渠道段硬件默认优先，铺开原有资料的六个方向，保留细分类、具名经营者及关联入口；软件以应用、社区、内容和企业方向组织。基础资料中同一体验店别名归并，三个社群入口放回对应主体下，腾讯云市场沿用已核对的补充来源。

交互主张：随着正常页面滚动，各列显露后续真实名称；点场景标题在本站展开全部细分类；关闭后回到原位置与焦点。没有渠道外跳、复制虚假节点、数量成绩宣传或无限自动轮播。

首眼检查：1440画面需要同时出现多种场景与足量具名经营者，手机使用单列场景、双列名称的独立构图。展开后名称必须完整可读，不能因为美化而裁掉长名称。技术与可读性检查不代替用户审美认可。

## 数据与关系

原资料240条名称均保留在两个产品模式及其关联入口中。模速AI体验店归并到Z·Pilot，三个关联社群归到对应内容主体，腾讯云市场沿用已核对的补充来源。当前没有把资料条数当作签约伙伴数量宣传。硬件与软件按经营方向分开，纯软件应用入口留在软件模式中。

## 核验范围
